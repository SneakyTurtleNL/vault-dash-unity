## GENERATION WORKFLOW

1. **Copy each prompt above**
2. Go to https://app.scenario.gg
3. Select model: **Vault Dash Characters** (or similar 2D illustration model)
4. Paste prompt
5. Set resolution: **1024×1024**
6. Set samples: **1** (cost-efficient)
7. Click Generate
8. Download PNG
9. Save to: `Assets/Resources/Characters/{character_name}.png`
