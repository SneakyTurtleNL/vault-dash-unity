## HOW TO USE

1. Copy entire prompt from above
2. Go to https://app.scenario.gg
3. Select model: **Vault Dash Characters** (any 2D illustration model works)
4. Paste full prompt exactly as written
5. Set resolution: **1024×1024**
6. Set samples: **1** (cost-efficient)
7. Click Generate
8. Download PNG
9. Save to: `Assets/Resources/Characters/{character_name}.png`
